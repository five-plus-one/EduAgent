# 多模态AI互动式教学智能体 - 前端工程规划与页面架构

> Developed by Yuran Wang

基于需求文档，为了满足低延迟的AI交互、实时的前端流式渲染 (SSE) 和多模态文件上传能力，前端在技术选型和架构规划上需要具备极高的响应性和强互动性。

## 1. 技术栈选型

| 类别 | 推荐技术 | 选型理由 (对应 API 设计) |
| --- | --- | --- |
| **基础框架** | **React 18 + Vite** + **TypeScript** | 适合构建高交互、富客户端的工作台应用；TypeScript 保障复杂的业务数据结构（如解析后的 PPT 结构化预览数据）的类型安全。 |
| **样式方案** | **Vanilla CSS (CSS Modules)** | 严格遵循要求，不使用 TailwindCSS。应用 CSS Modules 隔离作用域，使用 CSS 变量实现全局主题切换（Dark/Light）。大量运用玻璃拟物化设计 (Glassmorphism)，摆脱厚重感，打造 Premium 体验。 |
| **状态管理** | **Zustand** | 轻量级状态管理，极其契合这套系统的会话管理逻辑（当前激活的 `session_id`、用户鉴权 Profile等）。 |
| **网络请求** | **Axios** + **Fetch API** | 普通请求（文件上传、状态轮询）使用 Axios。核心的流式对话打字机效果（`/chat` 接口的 SSE 流）使用原生 Fetch 或 `@microsoft/fetch-event-source` 库。 |
| **UI 组件库** | **Radix UI** (无头组件库) | 提供无样式的底层交互（弹窗、下拉选项、分栏），将最大程度的设计自由度留给 Vanilla CSS 定义现代审美。 |
| **多媒体处理** | **MediaRecorder API** | 面向 `/audio-chat`，调用 Web 原生接口进行麦克风音频采集和上传。 |
| **Markdown解析** | **react-markdown** | 渲染 AI 返回的长篇教案、包含数学公式或代码的文本等。 |

## 2. 整体页面框架与布局设计 (Layout Design)

为扭转当前教育工具功能碎片化、多页跳转繁琐的沉疴，我们采用 **“沉浸式 App-like 单页工作台 (Workspace)”** 逻辑。所有核心教案流程均无需离开当前视窗。

### 2.1 整体应用框架 (App Shell)

整个页面撑满屏幕 (`100vw * 100vh`)，分为“折叠式侧边抽屉”与“主工作台”。
- **导航侧边栏 (Sidebar)**：
  - 顶部：Logo 与显眼的“新建教学课件设计”核心操作入口。
  - 中部：历史会话列表，采用清晰的时间轴分组。
  - 底部：教师个人信息及主题配置（读取 `/auth/me` 的 preference）。
- **知识库后台页面 (`/knowledge`)**：
  - 独立路由面板，提供给管理员进行文件拖拽上传、查看文档 Embedding 进度及向量化成功状态的大盘（对接 `5.x 接口`）。

### 2.2 核心工作台 —— 左右对称分栏设计 (Core Workspace Split-Pane)

针对教学设计过程，进入具体会话 (`/chat/[session_id]`) 后，核心区被切分为可拖动分隔线的两大阵地：**对话交互区（约占左侧 40%）** 与 **多模态结果可视区（约占右侧 60%）**。

#### 🔹 左侧面板：深层次对话输入枢纽 (Chat & Intent Area)
这里是接管教师教学思路的主枢纽。
- **动态信息流 (Message Stream)**：
  - 展示教师指令与系统反馈的瀑布流。AI 生成时带有平滑的流式文字逐显。
- **全能输入坞 (Omni-Dock Input)**：
  - 摒弃了干瘪的单行输入框，采用类似苹果悬浮控制台的设计，居于左侧界面的底部。
  - **资料挂链**：附带曲别针 Icon，直接拖拽或点击上传参考 PDF/视频，上传完毕时，以“胶囊卡片”悬停在输入框上方，带有环形的解析进度动画 (对接 `2.x 接口`)。
  - **语音秒输**：居中吸睛的麦克风按钮。按下后散发水波纹微动效；松开即调动音频转文字并投射回输入框。
  - **文字自适应**：随着意图输入的变长，输入框向顶部自适应拉伸。

#### 🔹 右侧面板：实时可视化与多文件编辑器 (Visual Preview Space)
这里是“生成式课件”的投影仪，教师不需下载即可检验效果。内容通过顶部的 Tab 划分为不同视图：
- **Tab 1: 课件白板 (PPT Preview) —— 核心重案区**：
  - 调用 `3.3 接口`，将生成的 JSON 解析为一张张宽幅圆角卡片，排列成为幻灯片缩略流。
  - 每行显示单张幻灯片，清晰展现标题与核心 Bullets。
  - **局部刷新机制**：教师选中某卡片后，该卡片翻转或呼出高亮光晕，附带局部指令输入框。教师输入“给公式加个例子”，指令单独通过 `3.4 接口` 返回后，该卡片施加“扫描骨架层”效果刷新自身内容。
- **Tab 2: 教案内参 (Word Preview)**：
  - 优雅呈现冗长的教案设计方案。排版上优化阅读，加粗重难点，展示教学活动设计。
- **右上侧：一键制裁 (Action Bar)**：
  - 当教师对左右侧定稿满意，点击右上方悬浮按钮群即可触发“成片导出” (`4.1 接口`)，并拉起下载链接等待动画。

## 3. 设计美学与体感基调 (Aesthetics & UX)

- **高级感色觉**：应用全局自定义 HSL 主题色卡。例如以纯净的钛白，或深邃的暗灰为主体（如暗黑模式），以低饱和度的蓝紫色作为高亮强调，远离廉价的后台模版感。
- **微互动与动效**：按钮 Hover 的轻微下沉、玻璃毛玻璃层叠、加载态的流光动画、局部修改成功时卡片的绿光边缘闪烁，为系统注入“生命力”。
- **排版结构**：采用 `Inter`/`Roboto` 无衬线现代字体集，加强标题字重落差，用干净的排版和间距替换繁复的表框。
