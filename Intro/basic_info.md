# EduAgent — 多模态 AI 互动式教学智能体

## 前言

当前教育信息化正在从"工具辅助"走向"智能共创"。然而，市面上的 AI 教学辅助工具普遍存在"功能碎片化"与"意图理解浅层化"两大顽疾——教师仍需跨越多个互不联通的软件平台来完成备课、制作 PPT、撰写教案等工作，且这些工具只能响应单轮、简单的指令，难以深度理解教师复杂的教学逻辑与个性化需求。

**EduAgent** 正是为打破这一困境而生。作为面向一线教师的新一代 AI 课件共创系统，EduAgent 将多轮对话、多模态文件解析、RAG 知识库检索、SSE 流式生成与结构化课件导出整合为一体，让教师从"事务型"操作者真正回归"设计型"导师角色。

本项目由五加一团队开发，选题来源于锐捷网络 2026 年企业命题赛题——**智能计算方向·多模态 AI 互动式教学智能体（应用类）**。

---

## 创意描述

EduAgent 的核心创意在于构建一个以"教学思路"为驱动核心的 **AI 智能协作闭环**。

传统备课模式下，教师的思路存在于脑中，课件制作工具只是"文字处理器"，二者之间存在显著的"意图-执行"鸿沟。EduAgent 通过以下三层创新弥合这道鸿沟：

1. **深度意图理解层**：通过多轮自然语言对话（支持文字 + 语音）主动询问、归纳、确认教师的教学目标、知识点逻辑、重难点分布，构建结构化教学意图。
2. **多模态知识融合层**：支持 PDF、Word、PPTX、TXT/Markdown 等参考资料上传，经 RAG 管道向量化后与教师意图深度融合，保证生成内容有据可查。
3. **确定性生成执行层**：大模型仅输出结构化 JSON 数据（幻灯片骨架），再由后端纯逻辑引擎（`python-pptx`）精准拼装为可下载的 .pptx 文件，彻底规避"幻觉式文件损坏"问题。

## 功能简介

| 功能模块 | 核心能力 |
|---|---|
| **多轮对话交互** | 文字 / 语音双通道输入，SSE 流式打字机效果，支持大模型深度思考过程可视化 |
| **多模态资料解析** | PDF、Word（.docx）、PPTX、TXT/MD 文件解析，异步向量化入库，进度实时轮询 |
| **RAG 知识库管理** | 全局知识库（管理员维护）+ 会话内专有文件，ChromaDB 语义检索，跨会话知识挂载 |
| **课件流式生成** | SSE 逐页推送，实时预览，支持"思考过程"透出，自动选取主题配色方案 |
| **Tool Calling 精准修改** | 大模型通过工具调用（UpdateSlide/AddSlide/DeleteSlide）直接修改数据库中的幻灯片，前端实时刷新 |
| **多主题视觉渲染** | 10 套预设高级主题（暗黑/亮色双系列），Canvas 几何引擎保证前后端像素一致 |
| **图片语义检索系统** | 上传图片 → Vision LLM 自动标注 → ChromaDB 向量检索 → 自动嵌入 PPT 对应位置 |
| **Word 教案生成** | 与 PPT 配套的 Markdown 格式讲义，前端支持一键浏览器端导出为 .docx |
| **标准格式导出** | 后端 `python-pptx` 引擎导出 .pptx，支持 OMML 数学公式、图片二进制内嵌，文件自包含 |

## 特色综述

### 🏆 亮点一：AI + 确定性双轨解耦生成

拒绝让大模型直接输出二进制文件。大模型专注于"智能决策"（输出 JSON Schema），后端引擎专注于"确定性执行"（拼装 PPTX），实现 100% 生成成功率。

### 🏆 亮点二：SSE 全链路流式体验

从对话响应到逐页课件生成，全程基于 Server-Sent Events 实现类 ChatGPT 的打字机效果。大模型思考过程（`reasoning_content`）实时透出，消除"黑盒等待焦虑"。

### 🏆 亮点三：图片语义检索系统（Vision RAG）

教师上传图片后，Vision LLM 自动生成中文描述与标签，向量化存入独立 ChromaDB 集合。PPT 生成时大模型用自然语言描述图片意图，后端自动余弦相似度检索最匹配图片并嵌入，无需手动选图。

### 🏆 亮点四：专业数学公式渲染

后端实现完整的 LaTeX → OMML 转换引擎，支持 `\frac`、`\sqrt`、`\sum`、`\int`、`\lim`、`\begin{cases}` 等大量 LaTeX 指令，导出的 PPTX 中数学公式为真正的 Office Math 对象，可在 PowerPoint 中自由编辑。

### 🏆 亮点五：前后端主题强一致性

前端通过 Canvas 几何引擎计算精确像素坐标；后端 `ppt_exporter.py` 实现同名 `PREMIUM_THEMES` 字典与与相同 `pick_premium_theme` 哈希算法，确保 PPT 预览与导出文件视觉完全一致。

## 开发工具与技术

### 后端

| 分类 | 技术选型 |
|---|---|
| 语言与框架 | Python 3.10+ · FastAPI · Uvicorn (ASGI) |
| 大语言模型 | 豆包 doubao-seed-2-0-pro（主力生成+工具调用）· doubao-vision-pro-32k（图片标注）|
| 嵌入模型 | text-embedding-3-large（文档与图片向量化）|
| 向量数据库 | ChromaDB（本地持久化，双集合隔离）|
| RAG 框架 | LangChain · langchain-openai · langchain-chroma |
| 数据持久层 | SQLite（开发期）· SQLAlchemy ORM（可无代码切换 MySQL）|
| 文件解析 | pypdf · python-docx · python-pptx |
| PPT 导出 | python-pptx + lxml（OMML 数学公式注入）|
| 鉴权 | PyJWT + bcrypt |
| 异步任务 | FastAPI BackgroundTasks（文件向量化 / 图片标注）|
| HTTP 客户端 | httpx（异步流式请求大模型 API）|

### 前端

| 分类 | 技术选型 |
|---|---|
| 基础框架 | React 18 · Vite · TypeScript |
| 样式方案 | Vanilla CSS + CSS Modules（Glassmorphism 设计语言）|
| 状态管理 | Zustand |
| 网络请求 | Axios + @microsoft/fetch-event-source（SSE）|
| UI 组件 | Radix UI（无头组件）|
| Markdown 渲染 | react-markdown |
| 数学公式渲染 | KaTeX（LaTeX 前端实时渲染）|
| 音频录制 | Web MediaRecorder API |

## 应用对象

- **主要用户**：各阶段在职教师（高校讲师、中小学教师、职业培训讲师等）
- **管理员**：系统管理员（负责维护全局知识库与默认图片库）
- **潜在延伸**：教研组、课程开发团队、在线教育内容生产者

---

## 应用环境

- **接入环境**：现代浏览器（Chrome / Edge / Firefox），无需安装任何客户端
- **部署形态**：支持本地 MVP 单机部署（SQLite，无需独立中间件）；生产环境可无缝迁移至 MySQL + 云存储
- **网络要求**：需稳定连接大模型 API 服务（豆包 doubao 系列，通过 OpenAI 兼容格式调用）
- **操作系统**：后端跨平台（Linux / macOS / Windows）；前端纯浏览器运行

## 结语

EduAgent 代表的不仅是一款备课工具的升级迭代，更是对"AI 在教育场景深层赋能"命题的一次完整实践。通过将大模型的创造力与确定性工程的可控性有机结合，EduAgent 将教师的教学思路视为第一生产力，以 AI 为"课件共创搭档"，真正实现了教师角色从"文字处理者"到"教学设计师"的转型。

随着知识库的持续积累与模型能力的演进，EduAgent 有望进一步覆盖微课视频脚本、互动小游戏设计、知识图谱构建等更广泛的教学创新场景，持续推动教育数字化向纵深发展。
